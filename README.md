# Linux Task Processing System

Systems programming project developed in C for Linux environments.  
This project includes multiple task-processing and mathematical modules using modular C architecture and Makefile-based compilation.

---

## 🚀 Features

- Fibonacci calculations
- Prime number analysis
- Cube operations
- Performance task processing
- File and data handling
- Modular systems programming structure
- Linux terminal execution

---

## 🛠 Technologies

- C
- Linux
- GCC
- Makefile
